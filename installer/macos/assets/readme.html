Before You Install

Xcode Command Line Tools

If you haven't installed Xcode Command Line Tools, the installer will prompt you to do so. Click Install in the dialog that appears, wait for it to finish, then re-run this installer.

Disk Space

Media Search Agent requires approximately 5 GB of free disk space for:

  • Python environment (~500 MB)
  • ML models — CLIP ViT-L/14, RT-DETR, InsightFace buffalo_l (~2.3 GB)
  • Search index — depends on your library size

First Launch

After installation, open MediaSearchAgent from your Applications folder or Launchpad. On the first launch, the menu bar icon will appear and the application will start in the background.

Open your browser to http://localhost:8000 to access the interface.

Unsigned Installer Notice

This installer is not yet signed with an Apple Developer certificate. If macOS blocks the installer, right-click (or Control-click) the .pkg and choose Open.
