Welcome to Media Search Agent

A local-first semantic search engine for your photo and video library. Search by natural language, browse by face, label people — all offline, nothing in the cloud.

This installer will:

  • Copy Media Search Agent to /Applications
  • Set up a Python environment in your home directory
  • Install required ML models (~2 GB download on first run)

Requirements: macOS 12 (Monterey) or later • Xcode Command Line Tools • ~5 GB free disk space

Installation takes 5–15 minutes depending on your internet connection.
